# تطبيق «نور الهدى» (Noor Al-Huda) - القرآن والأذكار والقبلة والمسابقات

تطبيق إسلامي حديث واحترافي مبني باستخدام **Android Studio** ولغة **Kotlin** وأحدث مكتبات **Jetpack Compose (Material 3)**.

---

## 🌟 المميزات الرئيسية

1. **القرآن الكريم (المصحف الشريف):**
   * فهرس السور الـ 114 مع البحث السريع بالاسم والرقم ونوع السورة (مكية/مدنية).
   * شاشة قراءة فائقة السلاسة (Smooth 120 FPS) بالرسم العثماني.
   * تحكم مرن في حجم الخط (Font Zoom Slider).
   * تفسير ميسر مدمج لكل آية بضغطة زر.

2. **الأذكار والأحاديث (حصن المسلم):**
   * تبويبات سريعة: أذكار الصباح، أذكار المساء، أذكار النوم، بعد الصلاة، والأحاديث النبوية.
   * عداد تفاعلي لكل ذكر مع اهتزاز لمسي هادئ (Haptic Feedback) وإشارة اكتمال.
   * شروحات ميسرة للأحاديث النبوية وتخريجها.

3. **السبحة الإلكترونية الذكية:**
   * قرص تسبيح دائري تفاعلي كبير مع تأثير ارتدادي ميكانيكي (Spring Animation).
   * عداد دورات مكتملة (33 / 100).
   * قائمة سريعة لأشهر الأذكار (سبحان الله، الحمد لله، لا إله إلا الله...).

4. **بوصلة القبلة ومواقيت الصلاة:**
   * بوصلة حية فائقة الانسيابية متصلة بمستشعر اتجاه الهاتف (`TYPE_ROTATION_VECTOR`) مع فلتر تنعيم (`Low-Pass Filter`) يمنع الارتعاش نهائياً.
   * حساب زاوية الكعبة المشرفة ومواقيت الصلاة محلياً 100% بدون إنترنت.

5. **قسم المسابقات والجوائز (سؤال الأسبوع):**
   * مسابقة أسبوعية/يومية باختيار عشوائي من أصحاب الإجابات الصحيحة.
   * **مشاركة مجانية بالكامل:** متوافق 100% مع سياسات متجر Google Play والشريعة الإسلامية.
   * نموذج إرسال الاسم ورقم الهاتف/المحفظة (فودافون كاش / إنستاباي).
   * لوحة شرف الفائزين السابقين لزيادة المصداقية.

## 🚀 حل مشكلة التقطيع أثناء السكرول (WhatsApp-Grade Performance)

تم حل مشكلة التقطيع في النصوص القرآنية الكبيرة من خلال:
1. **استخدام `LazyColumn` مع مفاتيح ثابتة `key = { verse.id }` و `contentType = { "verse_item" }`** لإعادة استخدام الواجهات (View Recycling) ومنع إعادة الرسم العشوائي (Recomposition).
2. **استخدام كائنات بيانات غير قابلة للتغيير `@Immutable`** لضمان استقرار شجرة Compose.
3. **عزل استعلامات وقراءة البيانات على خيط الخلفية `Dispatchers.IO`** عبر `Kotlin Coroutines & Flow`، مما يترك الـ UI Thread حراً بنسبة 100% لحركات السكرول والأنيميشن بتردد 60 و 120 هرتز.

## 🛠️ كيفية تشغيل التطبيق في Android Studio

1. افتح برنامج **Android Studio**.
2. اختر **Open** ثم حدد المجلد: `d:\apps\app_001`.
3. سيتعرف أندرويد ستوديو على المشروع ويبدأ بمزامنة Gradle تلقائياً.
4. اضغط زر **Run (▶)** أو قم ببناء ملف الـ APK عبر القائمة:
   `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`.

## 🔌 للمطور التالي: ربط المسابقة بالسيرفر (API Integration)

تم بناء قسم المسابقات بنمط **Repository Pattern** المفصول تماماً عن الواجهات:
* في المسار: `app/src/main/java/com/islamic/noor/data/repository/ContestRepository.kt`
* يوجد كلاس `LocalMockContestRepository` الذي يعمل حالياً بدون سيرفر.
* للربط بسيرفر خارجي (Firebase أو REST API أو Telegram Bot):
  1. أنشئ كلاس جديد ينفذ `ContestRepository` (مثلاً `RemoteContestRepository`).
  2. في شاشة `ContestScreen.kt`، استبدل `LocalMockContestRepository` بالكلاس الجديد بسطر واحد فقط:
     ```kotlin
     repository: ContestRepository = remember { RemoteContestRepository() }
     ```
  دون الحاجة لتعديل سطر واحد في واجهة المستخدم!
